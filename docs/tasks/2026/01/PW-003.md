## 🎯 Постановка задачи

### Описание

Мигрировать текущую мультирепозиторную структуру ProfitableWeb на Turborepo монорепо для улучшения developer experience,
упрощения управления зависимостями и обеспечения атомарности изменений.

**Текущее состояние:**

- ✅ `profitable-web-frontend/` - готов на ~60% (главная страница, инфраструктура)
- 📋 `profitable-web-backend/` - только структура, без кода
- 📋 `profitable-web-admin/` - только структура, без кода
- 📚 `profitable-web-docs/` - документация

### Цель

Создать единую монорепозиторную структуру с:

- Общими TypeScript типами между Frontend/Admin/Backend
- Единой системой сборки через Turborepo
- Общими конфигурациями (ESLint, Prettier, TypeScript)
- Кэшированием сборок для ускорения разработки
- Атомарными коммитами для связанных изменений

```bash

# 2. Инициализировать Turborepo
```

#### Этап 4: Настройка Turbo pipeline (~15 минут)

```json
// turbo.json
{

  "pipeline": {

      "dependsOn": ["^build"],
      "outputs": [".next/**", "out/**", "dist/**"]

    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {
      "dependsOn": ["^build"]
    },
    "test": {
      "dependsOn": ["^build"]
    },
    "type-check": {
      "dependsOn": ["^build"]
    }
  }
}

// Turborepo будет управлять им как обычным Node.js приложением
```


#### Этап 7: Создание структур для Backend и Admin (~15 минут)

````bash
# Backend structure
mkdir -p apps/api/src

# Backend package.json (shim для Turborepo)
cat > apps/api/package.json << 'EOF'
{
  "name": "@profitable-web/api",
  "version": "0.0.0",
  "private": true,
  "scripts": {
    "dev": "uv run uvicorn main:app --reload",
    "build": "echo 'Building Python API...'",
    "lint": "uv run ruff check .",
    "test": "uv run pytest",
    "type-check": "uv run mypy ."
  }
}
EOF

# Backend pyproject.toml
cat > apps/api/pyproject.toml << 'EOF'
[project]
name = "profitable-web-api"
version = "0.1.0"
description = "FastAPI backend for ProfitableWeb Research Lab"
requires-python = ">=3.11"
dependencies = [
    "fastapi>=0.100.0",
    "uvicorn[standard]>=0.23.0",
    "sqlalchemy>=2.0.0",
    "pydantic>=2.0.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "ruff>=0.1.0",
    "mypy>=1.0.0",
]
EOF

# Backend README
cat > apps/api/README.md << 'EOF'
# ProfitableWeb API

FastAPI backend for ProfitableWeb Research Lab.

## Development

```bash
# Install dependencies
uv sync

# Run dev server
uv run uvicorn main:app --reload
````

EOF

# Admin structure

### Дополнительная информация

**Почему Turborepo:**

- ⚡ Rust-powered кэширование (совместимо с Bun философией)
- 🔗 Shared types между Frontend/Admin/Backend без дублирования
- 📦 Workspace dependencies - единая версионирование зависимостей
- ⚛️ Атомарные коммиты - одно изменение API = один коммит
- 🚀 Параллельная сборка и тестирование всех приложений

**Текущее состояние Frontend:**

- Готовность: ~30% (главная страница, инфраструктура)
- Роуты: только `/` (главная)
- Компоненты: Header, HeadContent
- Отсутствуют: `[slug]`, `categories/[category]`, `about`, большинство компонентов

**Идеальный момент для миграции:**

- ✅ Инфраструктура Frontend готова - легко переносить
- ✅ Мало страниц и компонентов - минимум конфликтов
- ✅ Backend не начат - можно сразу интегрировать правильно
- ✅ Admin не начат - создастся уже в монорепо

**Риски:**

- ⚠️ Возможны проблемы с path aliases при переносе
- ⚠️ Bun workspace support может иметь нюансы

**Почему Python backend:**

Python выбран для агентских AI-систем (LangChain, Pydantic AI, FastAPI). Интеграция в Turborepo через package.json shim.
Внутри `apps/api` - чистый Python без компромиссов.

**Python в Turborepo:**

Turborepo заточен под Node.js, но через **package.json shim** мы превращаем его в агностичный оркестратор:

1. В `apps/api/package.json` прописываем npm scripts, которые вызывают `uv`
2. Turborepo видит backend как обычное Node.js приложение
3. Команды `turbo run dev` запускают `uv run uvicorn` автоматически
4. **Zero Friction** разработка - одна команда для всего стека

**Пример:**

```bash
# В корне монорепо - запустит ВСЁ (web, admin, api)
bun turbo dev

# Turbo сам пойдёт в apps/api и запустит: uv run uvicorn main:app --reload
```

**Альтернативы рассмотренные:**

1. Остаться на мультирепо - отклонено (боль с типами)
2. Гибридный подход (Frontend+Admin в моно, Backend отдельно) - возможно
3. Full monorepo с Turborepo - **выбрано**
