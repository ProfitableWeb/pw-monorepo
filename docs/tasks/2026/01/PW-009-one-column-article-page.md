## 🎯 Постановка задачи

### Описание

Реализовать одноколоночный лейаут для статей с возможностью использования блоков 100% ширины. Создать специализированные
компоненты для контента статей: блок самопроверки, блок ресурсов, блок автора и шапка статьи.

### Цель

- Создать одноколоночный лейаут для статей
- Реализовать интерактивный блок самопроверки (retrieval practice)
- Добавить блок ресурсов (ссылки на использованные материалы)
- Создать блок автора статьи
- Реализовать шапку статьи с выравниванием по контенту
- Обеспечить SEO-оптимизацию через Schema.org разметку

## 🛠️ Технические детали

### Использованные технологии

- **React** с TypeScript
- **SCSS** с CSS-переменными для темизации
- **Schema.org** разметка для SEO
- **CSS `ch` units** для оптимальной ширины строки (70ch)

### Ключевые решения

1. **Скрытие контента для SEO**: Использование `max-height`, `opacity`, `visibility` с `aria-hidden` вместо
   `display: none`
2. **Адаптивные паддинги**: Синхронизация паддингов шапки с контентом через медиа-запросы
3. **Модульная структура**: Каждый компонент в отдельной директории с собственными стилями
4. **Mock-данные**: Все данные вынесены в отдельные конфигурационные файлы
