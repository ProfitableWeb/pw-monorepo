## 🎯 Постановка задачи

### Описание

Аудит состояния проекта после паузы (последний коммит — 2026-03-22) показал, что все проверки качества красные, а
деплой-воркфлоу (`deploy.yml`, `deploy-dev.yml`) запускаются без линта и тестов — регрессии уходили в прод
незамеченными.

| Проверка                    | Было                    | Причина                                                                          |
| --------------------------- | ----------------------- | -------------------------------------------------------------------------------- |
| `pytest` (api)              | 27/27 ERROR             | JSONB (PW-056) не компилируется в SQLite; MCP lifespan запускался на каждый тест |
| `test_get_category_by_slug` | FAIL                    | `seed.py` не заполнял junction `article_categories` (PW-054)                     |
| `tsc` (admin)               | 4 ошибки                | поле `type` (PW-060) не маппилось из API; неиспользуемый импорт; тип Set         |
| `ruff` (api)                | 29 ошибок               | сортировка импортов, неиспользуемый импорт                                       |
| `vitest` (web)              | exit 1                  | нет ни одного теста                                                              |
| `mypy` (api)                | 350 ошибок в 120 файлах | накопленный долг — **вне скоупа**, отдельная задача                              |

## Реализация

- `apps/api/tests/conftest.py` — `@compiles(JSONB, "sqlite")` → `JSON`; один `TestClient` на сессию (MCP
  `StreamableHTTPSessionManager.run()` допускает один запуск), куки чистятся между тестами.
- `apps/api/src/seed.py` — `categories=[...]` для всех статей сида (primary-категория в junction, как в админском CRUD).
- `apps/admin/src/lib/api-client.ts` — `type` в `AdminArticleRaw`/`AdminArticleListItemRaw` и мапперах (раньше в
  рантайме `article.type` был `undefined`).
- `apps/web/package.json` — `test`: `vitest run --passWithNoTests` (одиночный прогон, не watch).
- `.github/workflows/ci.yml` — два джоба: API (ruff + pytest), Frontend (lint + type-check + test).
