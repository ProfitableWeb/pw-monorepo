## 🎯 Постановка задачи

### Описание

`uv run mypy .` (с `uv sync --extra dev`) — **173 ошибки в 30 файлах**. В `pyproject.toml` включён строгий режим
(`disallow_untyped_defs`, `warn_return_any`), но mypy нигде не запускается, поэтому долг рос с каждой задачей.

Аудит показал, что среди ошибок есть **настоящие баги**, а не только аннотации. Главный — в MCP-инструментах медиа
(вынесен в PW-067 как блокер).

### Разбивка ошибок

| Кластер                                                     | Ошибок | Файлы                            | Характер                                                           |
| ----------------------------------------------------------- | -----: | -------------------------------- | ------------------------------------------------------------------ |
| `@mcp.tool()` → `"object" has no attribute "tool"`          |     29 | `src/mcp/tools/*`                | `register(mcp_server: object)` вместо `FastMCP` — 1 правка на файл |
| `ctx: Context = None`                                       |     29 | `src/mcp/tools/*`                | нужно `ctx: Context \| None = None`                                |
| `MediaFile has no attribute alt_text/url/original_filename` |     12 | `src/mcp/tools/media.py`         | **баг** — поля не существуют, см. PW-067                           |
| `no-untyped-def`                                            |     38 | `tests/`, сервисы                | аннотации                                                          |
| Pillow (`LANCZOS`, `ImageFile` vs `Image`, `_getexif`)      |    ~10 | `services/media.py`, `avatar.py` | `Image.Resampling.LANCZOS`, публичный `getexif()`                  |
| `no-any-return`                                             |      9 | seo/yandex, config, logging      | `cast()` или типизированные ответы httpx                           |
| `import-untyped`                                            |      5 | jose, psutil                     | `types-python-jose`, `types-psutil` в dev-extras                   |
| `yandex_oauth.py: permissions dict vs list[str]`            |      2 | `services/seo/yandex_oauth.py`   | **вероятный баг** — схема ждёт список, приходит dict               |
| `slug.py: "type" has no attribute "id"`                     |      3 | `services/slug.py`               | generic по модели — `type[Article] \| type[Tag]`                   |
| `mcp_api_key.py: Name "User" is not defined`                |      1 | `models/mcp_api_key.py`          | `TYPE_CHECKING`-импорт                                             |
| `CategoryCreateRequest missing "color"`                     |      1 | `mcp/tools/categories.py`        | ложное — mypy не знает pydantic → включить `pydantic.mypy`         |

~60% ошибок закрываются двумя механическими правками в `src/mcp/tools/*`.

### Цель

`uv run mypy .` → `Success: no issues found`, mypy — обязательный шаг CI-джоба API.

### Критерии приемки

- [ ] Плагин `pydantic.mypy` в `[tool.mypy] plugins`
- [ ] Стабы `types-python-jose`, `types-psutil` в `[project.optional-dependencies].dev`, `uv.lock` обновлён
- [ ] MCP tools: `mcp_server: FastMCP`, `ctx: Context | None = None`
- [ ] Pillow: `Image.Resampling.LANCZOS`, `getexif()`, корректные типы `Image.Image`
- [ ] `yandex_oauth.permissions`: выяснить реальный формат ответа Яндекса, привести схему и код к нему
- [ ] Аннотации в `tests/` (или `[[tool.mypy.overrides]] module = "tests.*"` с `disallow_untyped_defs = false` —
      допустимо, тесты не прод)
- [ ] Ни одного `# type: ignore` без кода ошибки и комментария «почему»
- [ ] `ci.yml`: шаг `uv run mypy .` в джобе API
- [ ] pytest 27/27 (или больше после PW-067) остаётся зелёным

### Предложенное решение

1. Конфиг: плагин pydantic, стабы → пересчитать (часть ложных уйдёт).
2. Механика MCP (58 ошибок) — одним коммитом.
3. Pillow + slug + mcp_api_key — одним коммитом.
4. Вероятные баги (yandex permissions) — отдельным коммитом с объяснением.
5. Хвост `no-any-return`, аннотации.
6. Включить в CI.

Баг медиа MCP правится в PW-067 (с тестом), здесь только снимается в итоговом прогоне.
